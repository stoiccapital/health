# Vitality

A single-page allocation sim about health. One file, no backend. Open `index.html` in a browser.

Each second = one year. From 15 to 100. Pick height, training, diet, sleep, bad habits. See what compounds.

## What it teaches

- The male attractiveness window is narrow (FFMI 21-23, body fat 10-15%)
- Natural FFMI caps at 25 — the balanced path takes 10 years of perfect execution
- Gear overshoots the attractive peak and ends in early death
- Bad habits stack (workaholic + party + drink + smoke + weed)
- Sleep + diet + no vices → recovery → actually growing from training

## Three paths

- **Intensity (2× / week compound)** — caps at FFMI 23-24, low vitality cost
- **Balanced (4× / week, 1h)** — only path to FFMI 25, requires 10 perfect years
- **Volume (6× / week, 2h)** — can reach FFMI 25 but only with ~perfect recovery; stagnates otherwise

## Stack

Pure HTML + CSS + vanilla JS. No build step, no dependencies.
